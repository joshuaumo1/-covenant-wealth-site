# Codex Instructions for Covenant Wealth

Use these instructions when asking Codex to edit this repository.

## Project rule

Keep this project simple.

Do not convert the site to:

- React
- Next.js
- Astro
- Vue
- Svelte
- Tailwind
- WordPress
- any build tool

unless I explicitly ask.

This site should remain plain HTML, CSS, and JavaScript so a non-developer can manage it.

## Brand direction

Covenant Wealth equips faith-driven entrepreneurs to build enduring businesses, steward wealth, and strengthen communities.

The website has three audience pathways:

1. Entrepreneurs
2. Churches and ministries
3. Investors and donors

Each audience should have its own focused page while still feeling part of one Covenant Wealth platform.

## Tone

Use a tone that is:

- faith-driven but not cheesy
- premium but clear
- practical and grounded
- institutionally credible
- warm but not casual
- focused on stewardship, formation, business capability, community, capital readiness, and multiplication

Avoid language that sounds like hype, prosperity gospel, guaranteed wealth, investment promises, or fundraising pressure.

## What Codex should not do

Do not invent:

- partners
- testimonials
- financial returns
- investment products
- guarantees
- legal claims
- official affiliations
- exact dates or pricing unless provided

If content is missing, leave a placeholder and tell me what information is needed.

## Investor page caution

The investor page must stay informational. It should not promise returns, solicit securities, or provide investment advice. Keep the disclaimer unless legal counsel replaces it.
